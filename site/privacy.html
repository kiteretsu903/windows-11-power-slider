Privacy

Effective September 4, 2026

Summary

Windows 11 Power Slider does not collect, transmit, sell or share personal data. It has no accounts, analytics, advertising or telemetry.

The app

  • Power modes and preferences are handled locally through Windows APIs and current-user settings.
  • The app has no network client, updater, cloud service, background service or driver.
  • Keep Awake uses a process-scoped Windows request and is released when the app exits.

The website

This website uses no app-provided analytics, advertising trackers, forms or cookies. It is hosted by GitHub Pages, so GitHub may process technical request information under its Privacy Statement.

Open source

The complete source code is available on GitHub for inspection.
