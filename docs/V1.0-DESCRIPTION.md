# Windows 11 Power Slider v1.0.0

The first public release of a lightweight native Windows 11 power-mode tray app.

## Highlights

- Separate three-position sliders for plugged-in and battery modes.
- Acrylic flyout with automatic light and dark themes.
- Native animation and DPI-aware tray icons that reflect the current mode.
- Keep Awake with automatic release at critically low battery and on sleep transitions.
- Automatic English and Chinese selection, with a manual language choice in the tray menu.
- Portable build and a conventional per-user installer.
- Native C++ / Win32 with no .NET, WinUI 3, Qt or WebView runtime.

The build is unsigned, so Windows may show an unknown-publisher or SmartScreen warning.
