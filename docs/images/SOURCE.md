# Wallpaper

wallpaper.png was generated with the built-in GPT image tool using the user's satin-fold reference.
preview.png combines it with the UI composition in tools/render-readme.cjs.

wallpaper-light.png is a built-in GPT image edit of wallpaper.png. Its prompt:
Preserve the flowing satin folds and sweeping diagonal composition, changing the
palette to pale sky blue, icy blue and near-white. Replace black negative space
with light blue. Soft daylight, subtle blue shadows, no extra colors, text,
logos, UI windows or watermark.

preview.png places dark and light layouts side by side. Background opacity is
read from src/appearance.h so the image and application share the same setting.

Prompt direction:

Flowing folded satin/silk material and sculptural composition based on the reference.
Premium abstract desktop wallpaper, landscape 3:2. Broad flowing cobalt and deep
sapphire blue silk with glossy satin highlights against near-black charcoal.
Restrict colors to black, deep navy, royal blue and subtle icy blue highlights.
Large folds run diagonally from bottom left to upper right. Intentional black
negative space, soft studio light, refined composition. No glass tubes or loops,
text, UI, icons, logos or watermark. Leave attractive folds around a large
centered application window.
