# Windows 11 Power Slider v1.0.4

- Keep repeated startup and post-install launches silent.
- Fix flyouts remaining open after focus is lost or activation is denied.
- Register the tray before initializing fonts and window effects.
- Show the version in the tray context menu.
- Remove startup and diagnostic logging.
