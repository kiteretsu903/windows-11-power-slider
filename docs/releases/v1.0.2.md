# Windows 11 Power Slider v1.0.2

- Enable startup by default and repair stale startup paths, while preserving an existing opt-out.
- Run with High process priority.
- Add a desktop shortcut option, enabled by default.
- Fix uninstall registration and close the running app before upgrades or removal.
- Restore the tray icon after Explorer restarts and retry registration during sign-in.
- Fix duplicate tray click handling.

## 中文

- 默认注册开机启动并修复失效路径，保留用户已关闭的选择。
- 使用 High 进程优先级。
- 安装器新增默认勾选的桌面快捷方式选项。
- 修复卸载注册，以及升级或卸载时无法关闭程序的问题。
- Explorer 重启后恢复托盘图标，登录时注册失败自动重试。
- 修复托盘点击重复触发的问题。
