# Windows 11 Power Slider v1.0.3

- Add a circular blue glass application icon across the app, installer, website and READMEs. Mode-specific tray icons are unchanged.
- Improve small-icon rendering with high-quality downsampling and additional DPI sizes.
- Use a separate icon file for shortcuts and the uninstall entry to avoid stale Windows icon caches.
- Fix tray recovery paths that could leave the app running without a visible icon.
- Keep the last good image or use the app icon if mode-icon creation fails, then retry automatically.
- Restore missing tray registration on the next refresh, even without an Explorer notification.
- Handle duplicate taskbar recreation notifications reliably.
- Keep the existing left-click toggle and right-click menu behavior.

## 中文

- 应用、安装器、网站及 README 换用圆形蓝色玻璃图标，保留表示当前电源模式的托盘图标。
- 优化小图标缩小质量，并补齐更多 DPI 尺寸。
- 快捷方式与卸载条目使用独立图标文件，避免 Windows 沿用旧图标缓存。
- 修复应用仍在运行但托盘图标可能无法恢复的问题。
- 模式图标创建失败时保留上一张有效图标，或使用程序图标，并自动重试。
- 托盘登记丢失后在下一次刷新补回，无需依赖 Explorer 发出通知。
- 修复重复任务栏重建通知导致注册状态异常的问题。
- 保持左键开关面板、右键打开菜单的现有操作方式。
